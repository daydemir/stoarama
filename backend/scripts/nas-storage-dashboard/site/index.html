A map for planning cleanup

Start with a stream, then compare each local day’s clips and stitched coverage. The two timelines cover the same calendar day. More hours means more time represented; additional files do not necessarily mean additional coverage.

Clips
Original recorded files, usually one-minute clips. Coverage uses their registered start/end times, never an assumed one minute per file.
Stitched
Outputs acknowledged by the NAS. Coverage uses the included source intervals. Overlapping outputs count once in coverage, while their separate files still count toward storage.
Best 14 / Best 20
Previously selected retention windows, frozen on 19 October 2026. These are preservation markers, not permission to delete other days. A stream without a selected window needs review.
Fresh NAS evidence
Appears after the stat-only audit report has uploaded and passed its length/SHA check. Until then, day views use older inventory reports and delivery acknowledgements; files may since have moved or disappeared.
R2 size matches
A metadata listing found the expected object key with the same size. This is not a fresh content hash. Unchecked files are not proof that an object is missing. Object checks have their own timestamps. Completed prefix listings are refreshed at least daily; large unfinished listings resume every 30 minutes. “Not found” refers to that completed listing, not proof that a file exists only on the NAS.
Recycle bin and unknown files
Recycle-bin files are separate from active coverage. Unmapped paths, size mismatches, invalid filename bytes and scan errors remain explicit. Other shares and snapshots outside the app’s clips mount are not visible.
Hours and file sizes
Intervals are merged before hours are counted. Coverage crossing local midnight is split across days. A file’s bytes/count are assigned to its first covered day. GB/TB use decimal units; allocated blocks do not prove reclaimable space.

This dashboard has no deletion controls. Cleanup decisions wait for the completed audit, resolved evidence gaps, preservation of the selected windows, and confirmation of any replacement copy.
